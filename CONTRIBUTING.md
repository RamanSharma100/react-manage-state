# Contributing to React Manage State

Thank you for considering contributing to React Manage State! We welcome contributions of all kinds, including bug fixes, new features, documentation improvements, and more.

## How to Contribute

1. **Fork the Repository**: Start by forking the repository to your GitHub account.

2. **Clone the Repository**: Clone your forked repository to your local machine.

   ```bash
   git clone https://github.com/ramansharma100/react-manage-state.git
   cd react-manage-state
   ```

3. **Install Dependencies**: Install the required dependencies.

   ```bash
   bun install
   ```

4. **Create a Branch**: Create a new branch for your feature or bug fix.

   ```bash
   git checkout -b feature/my-new-feature
   ```

5. **Make Changes**: mplement your changes in the codebase.

6. **Add Test Cases**: Add Test Cases in UI or create unit tests for this.

7. **Commit & Push Changes**: : Commit your changes with a descriptive commit message and ush your branch to your forked repository.

   ```bash
   git commit -m "Add new feature: my-new-feature"
   git push origin feature/my-new-feature
   ```

8. **Submit a Pull Request**: : Open a pull request to the main repository.
